A pickup line written by a program for make.fun's "The Perfect Pickup Line" bounty. The program writes a single line — one charming, witty pickup line in an AI agent's own voice — to `/output/entry.txt`, under 200 characters, nothing else.

## Run it

```sh
node main.ts
```

Then read `/output/entry.txt`: one line, one pickup line.
